# 🐾 OpenClaw Messenger

OpenClaw — это не просто мессенджер, а экосистема для управления своей цифровой жизнью через AI-агентов. Мы объединяем привычный интерфейс общения с мощными инструментастями автоматизации, доступа к системе и долгосрочной памятью.

## 🌟 Главная идея

Превратить чат в полноценный командный центр. Вместо того чтобы переключаться между десятью приложениями, вы общаетесь с агентом, который:
- Имеет доступ к вашим файлам и терминалу.
- Помнит контекст прошлых разговоров (не только в рамках одной сессии).
- Умеет выполнять сложные цепочки действий (от поиска в сети до деплоя кода).
- Интегрируется с любыми мессенджерами (Telegram, Discord, Slack и др.).

## 🛠 Основные возможности

### 🤖 AI-Агенты
Агенты в OpenClaw — это не просто обертки над LLM. Они обладают:
- **Персональностью:** Определяется через `SOUL.md`.
- **Памятью:** Динамическое обновление `MEMORY.md` и ежедневные логи.
- **Инструментами:** Набор специализированных навыков (Skills) для работы с ОС, браузером и внешними API.

### 🏗 Архитектура
- **Workspace:** Изолированная рабочая среда для каждого агента.
- **Skills:** Модульная система расширения функционала.
- **Gateway:** Центральный узел, обеспечивающий связь между интерфейсами (мессенджерами) и логикой агентов.

## 🚀 Быстрый старт

### Установка
```bash
# Клонируйте репозиторий
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# Запустите setup скрипт
chmod +x setup.sh
./setup.sh
```

### Конфигурация
Все основные настройки живут в `openclaw.json`. Вы можете настроить:
- Подключаемые каналы (Telegram, WebChat и т.д.).
- Модели AI, которые будут использовать ваши агенты.
- Доступы и права безопасности.
