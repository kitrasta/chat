# 💬 Capsa Messenger

Фронтенд-клиент мессенджера на базе протокола [Matrix](https://matrix.org/). Проект делает упор на минималистичный интерфейс, высокую скорость работы и удобную навигацию.

> ⚠️ Проект в активной разработке. Некоторые функции ещё реализуются.

## 🚀 О проекте

Это **frontend-only** приложение — оно напрямую подключается к публичному домашнему серверу `matrix.org` (или другому Matrix-серверу) и не требует собственного бэкенда. Вся бизнес-логика авторизации, синхронизации комнат и сообщений работает через `matrix-js-sdk` прямо в браузере.

### Основной стек

- **React 19** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **Zustand** — управление состоянием
- **React Router DOM** — маршрутизация
- **CSS Modules** — стилизация компонентов
- **lucide-react** — иконки
- **matrix-js-sdk** — работа с Matrix API

## 🏗 Архитектура

Проект построен по методологии **Feature-Sliced Design (FSD)**:

```
src/
├── app/        # точка входа, роутер, глобальные стили
├── pages/      # страницы приложения (AuthPage, ChatPage, SettingsPage...)
├── widgets/    # крупные UI-блоки (ChatsList, ChatWindow, SideNav...)
├── features/   # пользовательские сценарии (CreateChat...)
├── entities/   # бизнес-сущности (user, chat, message, session)
└── shared/     # переиспользуемый код (ui, lib, helpers, matrix client)
```

## ✨ Что уже есть

- Авторизация через Matrix-аккаунт
- Сохранение сессии в `localStorage`
- Роутинг между разделами: чаты, контакты, звонки, настройки
- Тёмная тема в стиле Lucide
- Адаптивный лейаут с боковой навигацией

## 📦 В планах

- Загрузка списка комнат из Matrix
- Отправка и получение сообщений в реальном времени
- Поиск по чатам и сообщениям

## 🛠 Установка и запуск

```bash
# Клонирование репозитория
git clone git@github.com:kitrasta/chat.git
cd chat

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Проверка линтером
npm run lint
```
